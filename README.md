# Orientácia – geomorfologické celky Slovenska

Učebná appka na slepú mapu Slovenska (9. ročník, geografia).

- 58 celkov, ktoré treba vedieť (čísla a názvy podľa zošita, 1–78); celky začiernené v zošite sú na mape šrafované.
- 6 lekcií po oblastiach: 1. pozri si → 2. nájdi na mape → 3. napíš názov.
- Rýchly test (15 celkov) a veľký test (všetkých 58): appka ukáže celok, ty napíšeš názov.

Hranice celkov: geomorfologické členenie SR (Mazúr, Lukniš), verejná vrstva „FG SR Geomorfologické celky“ (UPJŠ) na ArcGIS Online.
Ako v zošite: Slovenské rudohorie = Veporské, Stolické, Volovské vrchy, Revúcka vrchovina a Čierna hora;
Spišsko-gemerský kras je rozdelený na Muránsku planinu a Slovenský raj; Bodvianska pahorkatina je pri Košickej kotline.
